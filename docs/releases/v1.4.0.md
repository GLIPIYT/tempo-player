# Tempo v1.4.0

## English

### Release overview

Tempo 1.4.0 introduces new lyric movement and word-highlighting modes, reduces unnecessary rendering work, and adds automatic recovery attempts for personal SoundCloud sessions. The update window now shows release importance with colored icon badges. This release is classified as **average — a feature update**.

### New features

#### Lyric movement and word highlighting

- **Choose how lines move.** In **Settings → Appearance → Lyrics**, select Smooth or Accelerated movement. Accelerated movement starts gently, moves more quickly through the middle, and slows near the next line; its overall transition is shorter. Fast passages retain a shortened animation.
- **Choose text filling.** Continuous mode keeps the gradual white fill. By word mode lights each complete word as the line's progress reaches it. Highlighting follows measured word widths and line progress; it does not introduce speech recognition or exact vocal word timestamps.
- **A clearer current word.** Upcoming words remain dim, completed words are brighter, and the current word gains a soft glow and a smooth 6% enlargement. Size and brightness transition gently without moving adjacent words. The current word has no separate underline.
- **Saved preferences.** Movement and text-fill modes are saved with the lyric appearance settings. Existing settings retain Smooth movement and Continuous filling by default, and reduced-motion preferences are respected.

#### Automatic SoundCloud session recovery

- **Recover a previously recognized personal login in the background.** Tempo checks the session at startup, periodically, and when session information or account authorization is requested. A currently valid token skips the browser recovery step.
- **Use the saved Tempo browser session.** When recovery is needed, Tempo temporarily opens the official SoundCloud site in a hidden browser window using its existing profile. The resulting session must pass a fresh account check before the recovery is accepted. The temporary window closes after the attempt, and successful recovery refreshes session status in the app.
- **Retry failed attempts after 24 hours.** The retry deadline is saved locally and survives restarting Tempo. Only one recovery attempt runs at a time, and each browser attempt has a time limit.
- **Respect manual account actions.** Signing out disables automatic recovery until the next manual sign-in; opening the sign-in window cancels background recovery. This feature applies to personal sessions, not built-in release credentials.
- **A recoverable login is required.** A server-revoked session or a profile without usable login data may still require manual sign-in. If the OAuth cookie was already missing when this version first recognized the account, signing in once may be necessary to enable recovery. This feature does not grant additional access to tracks.

#### Release importance badges

- **Identify the type of update.** The version list and selected release show compact badges with white text: gray **Bug Fix** with a gear, purple **minor updates** with a wrench, blue **feature updates (average)** with sparkles, and yellow **major updates** with a crown.
- **Subtle emphasis for major releases.** Major badges have a gentle glow and occasionally emit tiny white particles. Reduced-motion settings disable the particles.
- **Explicit release classification.** Release notes can specify an importance marker; older releases fall back to their version changes. Bug Fix is assigned explicitly to releases containing only bug fixes, rather than being inferred from a patch number. The marker is hidden from the changelog in this version of Tempo.

### Improvements

- **Lighter lyric rendering.** Positioning measures the required line instead of scanning every row, and text enlargement uses transforms instead of repeatedly changing the layout font size. Frame-driven fill updates are bounded, and separate word elements are created only for the active line.
- **Stable word boundaries.** Word-progress measurements use layout widths so the current word's enlargement does not change when the next word is highlighted. Underline positioning also accounts for the text's visual scale and alignment.
- **Less artwork work on Home.** Recommendation cards request smaller SoundCloud artwork first, load offscreen covers lazily, and decode images asynchronously. Artwork components avoid redundant renders, and cache-progress lookup is shared across cards. Full-size and small-image fallbacks remain available. A live-feed FPS increase has not been quantified.
- **Automatic latest-version information.** Opening **Settings → About** checks the latest stable release version without fetching the complete release list, notes, or installer metadata. Opening the update menu still loads the complete list. Failed or stalled checks show an error or empty value instead of leaving an endless ellipsis.
- **A stronger post-update celebration.** After an update, confetti uses more particles, varied sizes and motion, and a longer fall. It remains decorative, does not block controls, and respects reduced-motion preferences.

### Fixes and reliability

- **Adjust lyric offsets without reloading the screen.** Saving a timing shift updates the active shared lyrics in place instead of clearing them and restarting provider requests. The selected source and visible lyric view remain available while timing changes.
- **Fewer interruptions during lyric transitions.** Removed repeated whole-list measurements during animated text resizing and reduced avoidable frame work when lines change rapidly or timing is refined. Visual and automated regression checks cover rapid cues and long lyric lists; performance can still depend on the system and the track.
- **Bounded session recovery.** Hidden SoundCloud windows are excluded from visible window-state restoration, created off the UI thread, and closed on completion, cancellation, or timeout. Logout and manual login invalidate in-flight attempts, and credentials are not included in session-change notifications.

### Documentation and packaging

- Updated the application and Windows installer version to 1.4.0.
- Added documentation for explicit release importance, including Bug Fix classification.
- Saved the complete English and Russian notes, including the `average` importance marker, for the release history and updater.

### Known issues

- Rejected listening-history writes were observed in the development build. Their cause and impact in the packaged release have not been verified.
- Seeking during browser-backed playback of DRM-protected SoundCloud tracks can still be unavailable. Browser capture can take close to the track's full duration, depending on the track and account.

## Русский

### О релизе

Tempo 1.4.0 добавляет новые режимы движения лирики и подсветки слов, сокращает лишнюю работу при отрисовке и вводит автоматические попытки восстановления личной сессии SoundCloud. В окне обновлений появились цветные бейджи с иконками, обозначающие важность выпуска. Тип этого релиза — **average, среднее обновление с новыми функциями**.

### Новые возможности

#### Движение лирики и подсветка слов

- **Выбирайте движение строк.** В **Настройки → Оформление → Лирика** доступны режимы «Плавное» и «С ускорением». Второй начинается мягко, быстрее проходит середину движения и замедляется у следующей строки; сам переход короче. На быстрых участках сохраняется сокращённая анимация.
- **Выбирайте заполнение текста.** «Сплошное» сохраняет постепенное заполнение белым. В режиме «По словам» каждое слово загорается целиком, когда до него доходит прогресс строки. Подсветка рассчитывается по измеренной ширине слов и прогрессу строки; распознавание речи и точные вокальные тайминги отдельных слов не добавлялись.
- **Текущее слово заметнее.** Будущие слова приглушены, пройденные ярче, а текущее получает мягкое свечение и плавное увеличение на 6%. Размер и яркость меняются с коротким переходом без сдвига соседних слов. Отдельного подчёркивания у текущего слова нет.
- **Настройки сохраняются.** Режимы движения и заполнения записываются вместе с оформлением лирики. Для существующих настроек по умолчанию остаются плавное движение и сплошное заполнение; системное уменьшение анимации учитывается.

#### Автоматическое восстановление сессии SoundCloud

- **Восстанавливайте ранее распознанный личный вход в фоне.** Tempo проверяет сессию при запуске, периодически и при запросах состояния входа или авторизации аккаунта. Если текущий токен действителен, браузерный этап восстановления пропускается.
- **Используется сохранённая браузерная сессия Tempo.** При необходимости приложение временно открывает официальный сайт SoundCloud в скрытом окне со своим существующим профилем. Восстановление принимается только после новой проверки доступа к аккаунту. Временное окно закрывается после попытки, а успешное восстановление обновляет состояние входа в приложении.
- **Повтор после неудачи — через 24 часа.** Срок следующей попытки сохраняется локально и переживает перезапуск Tempo. Одновременно выполняется только одна попытка; время работы временного браузерного окна ограничено.
- **Ручные действия с аккаунтом учитываются.** Выход отключает автоматическое восстановление до следующего ручного входа; открытие окна авторизации отменяет фоновую попытку. Функция относится к личной сессии, а не к встроенным учётным данным релиза.
- **Нужна сессия, которую можно восстановить.** Если сервер отозвал вход или в профиле не осталось пригодных данных, может потребоваться ручная авторизация. Если OAuth-cookie уже отсутствовала, когда эта версия впервые распознавала аккаунт, для включения восстановления может понадобиться один раз войти заново. Дополнительных прав на прослушивание треков функция не предоставляет.

#### Бейджи важности релизов

- **Тип обновления виден сразу.** В списке версий и у выбранного релиза показываются компактные бейджи с белым текстом: серый **Bug Fix** с шестерёнкой, фиолетовое **небольшое обновление** с ключом, голубое **обновление функций (average)** с искорками и жёлтое **крупное обновление** с короной.
- **Ненавязчивый акцент крупных выпусков.** Их бейджи слегка светятся и изредка выпускают маленькие белые частицы. При уменьшении анимации частицы отключаются.
- **Важность можно задать явно.** В описании релиза поддерживается специальная отметка; для старых выпусков используется изменение номера версии. Bug Fix назначается явно выпускам только с исправлениями, а не определяется по одному patch-номеру. В этой версии Tempo служебная отметка скрыта из текста изменений.

### Улучшения

- **Более лёгкая отрисовка лирики.** Для позиционирования измеряется нужная строка вместо обхода всех строк, а увеличение текста выполняется трансформацией вместо постоянного изменения размера шрифта в вёрстке. Частота покадровых обновлений заполнения ограничена, отдельные элементы слов создаются только у активной строки.
- **Стабильные границы слов.** Прогресс измеряется по ширине слов в вёрстке, поэтому увеличение текущего слова не меняет момент подсветки следующего. Позиционирование полоски также учитывает визуальный масштаб текста и выравнивание.
- **Меньше работы с обложками на главной.** Карточки рекомендаций сначала запрашивают уменьшенные изображения SoundCloud, лениво загружают обложки за пределами видимой области и декодируют их асинхронно. Компоненты обложек избегают лишних перерисовок, поиск прогресса кэширования общий для карточек. Резервные варианты полноразмерных и маленьких изображений сохранены. Прирост FPS живой ленты количественно не измерялся.
- **Последняя версия проверяется автоматически.** При открытии **Настройки → О программе** запрашивается номер последнего стабильного релиза без загрузки полного списка выпусков, описаний и сведений об установщиках. Полный список по-прежнему загружается при открытии меню обновлений. Ошибка или зависший запрос завершаются сообщением либо пустым значением вместо бесконечного троеточия.
- **Более заметное конфетти после обновления.** Стало больше частиц, добавлено разнообразие размеров и движения, увеличена длительность падения. Эффект остаётся декоративным, не блокирует управление и учитывает уменьшение анимации.

### Исправления и стабильность

- **Смещение таймингов без перезагрузки экрана.** Сохранение сдвига обновляет текущую общую лирику на месте вместо её очистки и повторного запроса к провайдерам. Выбранный источник и экран текста сохраняются во время изменения таймингов.
- **Меньше прерываний при переходах лирики.** Убраны повторные измерения всего списка при анимированном изменении размеров текста и сокращена лишняя покадровая работа на быстрых строках и при уточнении таймингов. Визуальные и автоматические регрессионные проверки охватывают быстрые переходы и длинные списки; производительность всё ещё зависит от системы и трека.
- **Ограниченные по времени попытки восстановления входа.** Скрытые окна SoundCloud исключены из восстановления видимого состояния окон, создаются вне UI-потока и закрываются после завершения, отмены или тайм-аута. Выход и ручная авторизация отменяют выполняющиеся попытки; уведомления об изменении сессии не содержат учётных данных.

### Документация и сборка

- Версия приложения и установщика Windows обновлена до 1.4.0.
- Добавлена документация по явному указанию важности релиза, включая категорию Bug Fix.
- Полное описание на английском и русском вместе с отметкой `average` сохранено для истории релизов и окна обновлений.

### Известные проблемы

- В dev-сборке замечены отклонённые записи истории прослушиваний. Причина и влияние на устанавливаемый релиз пока не подтверждены.
- Перемотка DRM-защищённых треков SoundCloud при воспроизведении через браузер по-прежнему может быть недоступна. Браузерный захват может занять почти всю длительность песни в зависимости от трека и аккаунта.
