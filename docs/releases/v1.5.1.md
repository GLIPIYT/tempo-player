# Tempo v1.5.1

## English

### Release overview

A Bug Fix update for stalls on Home, during synced lyrics, and in the update window. It also adds integrity checks for installers downloaded through Tempo.

### Fixes and reliability

- **Fewer stalls on Home.** Recommendation profiles and duplicate recording groups now use indexed lookups for work that repeatedly scanned the listening and recommendation data. This reduces the time spent blocking the interface with a large history.
- **Library sections load with less work.** Home fetches its library data in one request. Custom mix generation waits for the main sections to load, and the rule editor loads its genre data when opened. Mix rules also reuse distinct listening times when filtering by time of day.
- **Smoother synced lyrics.** Playback ticks update the clock and seek bar without rerendering the whole lyrics screen. Word highlighting continues between line changes, and the covered main player bar pauses its frame-by-frame progress animation. Reopening lyrics reuses recent provider results for the same track.
- **Lower memory pressure during lyric analysis.** Vocal and word-timing analysis reuse decoded audio where possible. The word-timing worker releases its temporary model tensors after use.
- **Less work during startup and navigation.** Detail pages load on demand. The title bar, sidebar, queue, and playback integrations subscribe to the player data they need, reducing updates as a track plays.
- **A lighter update window.** Startup checks the latest version before fetching full release notes. The window reuses rendered notes, and the large v1.5.0 poster has a lighter preview that still opens the full-size image. The celebration skips creating particles when the system requests reduced motion.
- **Installer integrity checks.** Tempo accepts the expected Windows installer from the official GitHub release, verifies its size and SHA-256 digest, and checks the staged file again before launch. This applies when installing updates from Tempo v1.5.1 or later.

### Documentation and packaging

- Updated frontend and desktop dependencies. The release workflow pins its GitHub Actions dependencies to reviewed revisions and uses narrower permissions.
- Official builds no longer bundle a shared SoundCloud session or a Wallhaven API key. You can sign in to SoundCloud from the app. Wallhaven filters that require a key use a personal key supplied through the `WALLHAVEN_API_KEY` environment variable.
- Development builds have a diagnostics panel on the right edge for recording slow frames and React renders, saving a local log, and capturing a WebView2 JavaScript CPU profile.

### Download

- **Windows x64 installer (NSIS)** is available from [Tempo Releases](https://github.com/GLIPIYT/tempo-player/releases) after the build is published.

## Русский

### О релизе

Выпуск Bug Fix с исправлениями подвисаний на главной, в синхронизированной лирике и в окне обновлений. Tempo также проверяет целостность установщика, скачанного через приложение.

### Исправления и стабильность

- **Меньше подвисаний на главной.** При расчёте профиля рекомендаций и обработке групп одинаковых записей Tempo использует индексы там, где раньше многократно перебирал историю и данные рекомендаций. Это сокращает блокировки интерфейса при большой истории прослушиваний.
- **Разделы медиатеки загружаются с меньшей нагрузкой.** Главная получает данные медиатеки одним запросом. Свои подборки пересобираются после загрузки основных секций, а жанры подгружаются при открытии редактора правил. Для фильтра по времени суток достаточно уникальных минут прослушивания.
- **Плавнее синхронизированная лирика.** Таймер и полоса перемотки обновляются без перерисовки всего экрана. Подсветка слов продолжается внутри строки, а скрытый основной плейбар приостанавливает покадровую анимацию прогресса. При повторном открытии лирики Tempo использует недавние результаты провайдеров для того же трека.
- **Меньше расход памяти при анализе лирики.** Анализ вокала и таймингов слов по возможности использует одни и те же декодированные данные. Модель таймингов слов освобождает временные данные после обработки.
- **Меньше работы при запуске и навигации.** Страницы с подробностями загружаются при открытии. Заголовок, сайдбар, очередь и интеграции воспроизведения подписываются на нужные им данные плеера и реже обновляются во время трека.
- **Окно обновлений стало легче.** При запуске Tempo сначала проверяет номер последней версии и при необходимости загружает полные заметки. Окно переиспользует отрисованный текст и показывает облегчённое превью большого баннера v1.5.0. По нажатию открывается исходное изображение. При системном уменьшении движения частицы конфетти не создаются.
- **Проверка целостности установщика.** Tempo скачивает ожидаемый установщик Windows из официального релиза на GitHub, сверяет размер и SHA-256, а затем повторно проверяет файл перед запуском. Проверки действуют при установке обновлений из Tempo v1.5.1 и новее.

### Документация и сборка

- Обновлены зависимости интерфейса и настольного приложения. Сборка релиза использует закреплённые ревизии GitHub Actions и более узкие разрешения.
- В официальные сборки больше не встраиваются общая сессия SoundCloud и ключ Wallhaven. Войти в SoundCloud можно из приложения. Для фильтров Wallhaven, требующих ключ, можно задать личный ключ через переменную окружения `WALLHAVEN_API_KEY`.
- В dev-сборке справа открывается панель диагностики. Она записывает длинные кадры и рендеры React, сохраняет локальный журнал и умеет снимать CPU-профиль JavaScript в WebView2.

### Скачать

- **Установщик Windows x64 (NSIS)** появится в разделе [релизов Tempo](https://github.com/GLIPIYT/tempo-player/releases) после публикации сборки.
