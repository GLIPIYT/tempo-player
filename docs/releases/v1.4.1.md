# Tempo v1.4.1

## English

### Release overview

A Bug Fix release for word-by-word lyrics and unnecessary rendering work on the Home page. It addresses crowded words, repeated updates of recommendation lists, and avoidable work at the start of synchronized lyrics.

### Fixes and reliability

- **Readable spacing in word-by-word lyrics.** Whitespace between highlighted words is preserved, with additional breathing room and less horizontal enlargement of the current word. The current word keeps its animated emphasis and glow; completed words remain brighter than upcoming words.
- **Less rendering work during lyric playback.** Synchronized lyrics no longer subscribe to every player progress update. Unchanged lyric rows are reused when a cue advances, and the initially active cue is selected before the first render instead of rebuilding the list immediately afterward. Word-level elements are still created only for the active row.
- **Steadier lyric animation updates.** The fill animation follows display frames without the previous timing check that could skip alternate frames at a nominal 60 Hz refresh rate. Geometry measurements finish before underline styles are changed, avoiding an extra forced layout while measuring word boundaries.
- **Home lists stop following every timer tick.** Starting tracks from Home no longer requires subscribing the whole page to playback position changes. This removes repeated list rendering and repeated setup of recommendation visibility observers during playback.
- **Cache progress updates stay local.** Download percentages and completion animations update the affected recommendation's cache control instead of rebuilding both recommendation shelves for each progress event. Retry controls and the existing completion fade remain available.
- **Fewer periodic recommendation updates.** The retry cooldown uses one deadline timer instead of rebuilding the shelves every second. Repeated visibility callbacks with the same visible tracks no longer trigger redundant cache checks; periodic and page-visibility refreshes are retained.
- **Bounded work while scrolling long recommendation lists.** Trimming old cards is scheduled at most once per animation frame and checks only the leading cards needed for the next trim, rather than measuring the entire rail on every scroll event. The visible scroll anchor is preserved when those cards are removed.

### Documentation and packaging

- Application and Windows installer version updated to 1.4.1.
- This release is explicitly marked **Bug Fix** in the update window.
- Automated checks cover lyric whitespace, inactive lyric rows, compact pause rows, and track-specific cache progress notifications. No manual playback checks or dev-player session were run for this patch; live FPS improvements have not been measured.

### Known issues

- Rejected listening-history writes were observed in a dev build before this patch. Their cause and impact on packaged releases remain unconfirmed; this patch does not change that path.
- Seeking in DRM-protected SoundCloud tracks through browser playback may remain unavailable. Browser capture can still take close to the track's duration, depending on the track and account.

## Русский

### О релизе

Выпуск Bug Fix для режима лирики по словам и лишних перерисовок главной страницы. Исправляет тесные интервалы между словами, повторные обновления списков рекомендаций и лишнюю работу при запуске синхронизированной лирики.

### Исправления и стабильность

- **Читаемые интервалы в лирике по словам.** Пробелы между подсвечиваемыми словами сохраняются, интервалы немного увеличены, а текущее слово меньше растягивается по горизонтали. Его анимированное увеличение и свечение сохранены; пройденные слова остаются ярче предстоящих.
- **Меньше перерисовок при воспроизведении лирики.** Синхронизированный текст больше не подписан на каждое обновление прогресса плеера. При смене строки неизменившиеся строки используются повторно, а первая активная строка определяется до первоначального рендера вместо немедленного повторного построения списка. Отдельные элементы слов по-прежнему создаются только у активной строки.
- **Более равномерное обновление анимации лирики.** Заполнение следует кадрам экрана без прежней проверки времени, которая могла пропускать каждый второй кадр при номинальной частоте 60 Гц. Измерения геометрии завершаются до изменения стилей полоски, чтобы не вызывать дополнительный принудительный пересчёт вёрстки при измерении границ слов.
- **Списки на главной больше не следуют каждому тику таймера.** Запуск песен с главной больше не требует подписывать всю страницу на положение воспроизведения. Убраны повторные перерисовки списков и повторное создание наблюдателей видимости рекомендаций во время прослушивания.
- **Прогресс кэширования обновляется локально.** Проценты загрузки и анимация завершения обновляют кнопку нужной рекомендации вместо повторного построения обеих полок на каждом событии прогресса. Кнопки повтора и прежнее плавное исчезновение после завершения сохранены.
- **Меньше периодических обновлений рекомендаций.** Ожидание перед повторным запросом использует один таймер до нужного момента вместо перестроения полок каждую секунду. Повторные уведомления с теми же видимыми треками больше не вызывают лишних проверок кэша; периодическое обновление и обновление при изменении видимости страницы сохранены.
- **Ограниченная работа при прокрутке длинных рекомендаций.** Удаление пройденных карточек планируется не чаще одного раза за кадр и проверяет только начальные карточки, нужные для очередного удаления, вместо измерения всей ленты при каждом событии прокрутки. При удалении этих карточек положение видимого списка сохраняется.

### Документация и сборка

- Версия приложения и установщика Windows обновлена до 1.4.1.
- В окне обновлений выпуск явно помечен как **Bug Fix**.
- Автоматические проверки охватывают пробелы лирики, неактивные строки, компактные строки пауз и адресные уведомления о прогрессе кэширования. Ручные проверки воспроизведения и запуск dev-плеера для этого патча не выполнялись; прирост FPS живой ленты не измерялся.

### Известные проблемы

- До этого патча в dev-сборке замечены отклонённые записи истории прослушиваний. Их причина и влияние на устанавливаемые релизы пока не подтверждены; этот патч не меняет соответствующий механизм.
- Перемотка DRM-защищённых треков SoundCloud через браузер по-прежнему может быть недоступна. Браузерный захват может занять почти всю длительность песни в зависимости от трека и аккаунта.
