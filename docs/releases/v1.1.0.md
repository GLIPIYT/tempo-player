# Tempo v1.1.0

## English

### Release overview

Tempo 1.1.0 moves desktop playback to a native audio engine and adds browser-backed playback for more SoundCloud tracks, including some that require an authorized account. The update connects playback to system controls, improves SoundCloud caching and recovery, and keeps lyric tools in step with native audio.

### New features

#### Native desktop playback and system controls

- **Desktop playback now uses a native audio engine.** The main player and floating mini-player share the same queue, position, volume, repeat, and shuffle state. Queue state lives outside the main UI renderer and can survive a renderer reload; playback still runs inside Tempo, and this does not guarantee recovery from every crash.
- **Use system and tray controls.** Play, pause, previous, next, and supported system seek controls operate on the same queue. The operating system can show the current track and playback position.
- **Lyric tools follow desktop playback.** The lyrics overlay tracks the native playback clock, and the editor can use native audio analysis for vocal timing correction.

#### SoundCloud account playback and caching

- **Manage personal SoundCloud sign-in in Settings → About.** Sign in for tracks that require account access and sign out of the personal session there; the built-in session has no sign-out control. A yellow warning identifies a missing, unverified, or expired session. Public tracks remain available without signing in, and protected playback still depends on your account and SoundCloud’s current service.
- **More SoundCloud sources can play and be cached.** Tempo can use browser playback when a regular stream is unavailable, including for some protected tracks. A protected track’s cache is re-encoded from playback as Opus at 192 kb/s VBR; it is not the original source file.
- **Choose capture parallelism in Settings → General.** These controls appear at the bottom of General once Tempo validates the SoundCloud session saved inside the app. Automatic mode selects 1–8 capture blocks based on CPU load and available memory. Manual mode lets you choose 1–12 blocks.
- **Recover from a timed-out multi-block capture.** If seeking between capture blocks times out, Tempo retries once from the beginning as a single full-track capture. This fallback can take about as long as the track itself.

### Improvements

- **SoundCloud cache actions share one recovery flow.** Cache from likes, recommendations, track menus, drag-and-drop, and playlist saves; progress and failures stay visible, retry actions are available, completed files are reused, and cached tracks retain metadata for offline playback. Caching handles ordinary HLS audio as well as progressive streams, with other available fallbacks where possible.
- **Spectrum visualization is steadier.** Frames are held through brief delivery gaps instead of disappearing during a short interruption.

### Fixes and reliability

- **Incomplete SoundCloud downloads are not marked as cached.** Preview-only, empty, or unfinished downloader outputs are rejected; cache status is set only after a completed file is available.
- **Offline cache hits retain track information.** Existing SoundCloud cache files can restore their catalog metadata without downloading the audio again.
- **Protected tracks remain eligible in SoundCloud lists.** Search, artist, playlist, and recommendation results no longer exclude a track solely because it uses an account-protected stream.
- **Playback recovers more carefully.** Repeat-one replays loaded media when possible and retries source resolution if needed. The native output can also try to reconnect and resume from the current position after some stalls or audio-device interruptions; recovery depends on the device and source remaining available.
- **Settings scrolling avoids conflicting animations.** Scrolling or interacting inside Settings cancels an earlier scroll animation routed from outside the content, preventing it from pulling the page back.
- **SoundCloud helper windows stay out of view.** Browser cookie detection no longer flashes a console window, and temporary playback or capture windows no longer appear as blank white rectangles.

### Documentation and packaging

- Updated the README and architecture guide to describe native playback, SoundCloud sessions and caching, and the managed decoder requirement. Streaming and some formats, including Opus, may need an FFmpeg decoder downloaded on first use; that first download requires an internet connection.
- Consolidated bundled third-party license information in `LICENSE` and adjusted release automation to preserve complete multiline release notes.

### Known issues

- **Seeking and rewinding do not work during DRM-protected SoundCloud online playback in this release.** The capture fallback above only retries a cache operation as one full-track pass; it does not restore online seeking.
- **Protected playback can take several seconds to start.** Browser-backed caching may take close to the full track duration. Access and playback availability vary by track and SoundCloud account; this release does not guarantee compatibility with every protected track.

## Русский

### О релизе

В Tempo 1.1.0 настольный плеер перешёл на нативный аудиодвижок, а для SoundCloud появилось воспроизведение через браузер для большего числа треков, включая некоторые композиции, требующие авторизации. Обновление связывает плеер с системным управлением, улучшает кэширование SoundCloud и восстановление воспроизведения, а также синхронизирует инструменты лирики с нативным звуком.

### Новые возможности

#### Нативное воспроизведение и системное управление

- **Настольный плеер использует нативный аудиодвижок.** Основной плеер и плавающий мини-плеер используют одну очередь и общие значения позиции, громкости, повтора и перемешивания. Состояние очереди находится вне основного UI-рендерера и может пережить его перезапуск; звук по-прежнему воспроизводится внутри Tempo, и это не гарантирует восстановление после любого сбоя приложения.
- **Используйте системные и трэй-элементы управления.** Воспроизведение, пауза, предыдущий и следующий треки, а также поддерживаемая системная перемотка управляют той же очередью. Операционная система может показывать текущий трек и позицию воспроизведения.
- **Инструменты лирики следуют за настольным плеером.** Оверлей лирики использует нативную позицию воспроизведения, а редактор может применять нативный анализ звука для коррекции тайминга вокала.

#### Воспроизведение и кэширование SoundCloud с авторизацией

- **Управляйте личным входом в SoundCloud в разделе «Настройки» → «О программе».** Войдите для воспроизведения треков, требующих доступа, и выйдите из личной сессии; для встроенной сессии кнопки выхода нет. Жёлтое предупреждение указывает на отсутствующую, непроверенную или истёкшую сессию. Публичные треки доступны без входа, а воспроизведение защищённых композиций зависит от аккаунта и работы SoundCloud.
- **Можно воспроизводить и кэшировать больше источников SoundCloud.** Если обычный поток недоступен, Tempo может использовать воспроизведение через браузер, в том числе для некоторых защищённых треков. Кэш защищённого трека создаётся из воспроизводимого звука в формате Opus с переменным битрейтом 192 кбит/с; это перекодированная запись, а не исходный файл.
- **Настройте параллельность захвата в разделе «Настройки» → «Общие».** Эти элементы появляются внизу раздела после проверки сессии SoundCloud, сохранённой внутри Tempo. Автоматический режим выбирает 1–8 блоков с учётом загрузки процессора и доступной памяти. В ручном режиме можно выбрать 1–12 блоков.
- **Повторите захват после тайм-аута многоблочной записи.** Если при переходе между блоками возникает тайм-аут перемотки, Tempo один раз запускает запись заново с начала одним блоком на всю длительность. Такой запасной режим может занять примерно столько же, сколько длится трек.

### Улучшения

- **Все действия кэширования SoundCloud используют общий путь восстановления.** Запускайте кэширование из лайков, рекомендаций, меню трека, перетаскивания и сохранения плейлистов. Прогресс и ошибки видны, задачу можно повторить, готовые файлы используются повторно, а метаданные сохраняются для офлайн-воспроизведения. Кэширование поддерживает обычные HLS-потоки наряду с progressive-потоками и по возможности использует другие варианты.
- **Визуализатор спектра работает стабильнее.** Кадры сохраняются при кратких задержках передачи, а не пропадают из-за короткого прерывания.

### Исправления и стабильность

- **Неполные загрузки SoundCloud не считаются закэшированными.** Превью, пустые и незавершённые файлы отклоняются; статус кэша выставляется только после появления готового файла.
- **Существующий офлайн-кэш сохраняет сведения о треке.** Метаданные SoundCloud можно восстановить по уже имеющемуся файлу, не загружая аудио заново.
- **Защищённые треки остаются доступными в списках SoundCloud.** Поиск, страницы исполнителей и плейлистов, а также рекомендации больше не исключают трек только из-за того, что для его потока нужна авторизация.
- **Воспроизведение восстанавливается надёжнее.** Повтор одной композиции снова запускает уже загруженный трек, если возможно, и повторно разрешает источник при необходимости. Нативный аудиовыход также может подключиться заново и продолжить с текущей позиции после некоторых зависаний или сбоев устройства; восстановление зависит от доступности устройства и источника.
- **Прокрутка настроек больше не конфликтует с предыдущей анимацией.** Прокрутка и действия внутри содержимого отменяют анимацию, запущенную прокруткой снаружи, поэтому она больше не возвращает страницу назад.
- **Вспомогательные окна SoundCloud не мешают работе.** Фоновая проверка браузерной сессии больше не показывает консольное окно, а временные окна воспроизведения и захвата больше не отображаются как пустые белые прямоугольники.

### Документация и сборка

- Обновлены README и описание архитектуры: добавлены сведения о нативном воспроизведении, сессиях и кэшировании SoundCloud, а также об управляемом декодере. Для потокового звука и некоторых форматов, включая Opus, при первом использовании может понадобиться загрузить декодер FFmpeg; для первой загрузки нужен интернет.
- Сведения о сторонних лицензиях объединены в `LICENSE`, а релизная автоматизация теперь сохраняет полные многострочные заметки.

### Известные проблемы

- **Перемотка назад и вперёд не работает при онлайн-воспроизведении DRM-защищённых треков SoundCloud в этой версии.** Запасной захват выше только повторяет кэширование одним проходом на всю длительность и не восстанавливает перемотку во время онлайн-воспроизведения.
- **Защищённый трек может запускаться несколько секунд.** Кэширование через браузер может занять почти всю длительность трека. Доступность зависит от конкретного трека и аккаунта SoundCloud; эта версия не гарантирует совместимость со всеми защищёнными треками.
