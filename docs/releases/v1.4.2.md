# Tempo v1.4.2

## English

### Release overview

A Bug Fix release focused on lyric freezes, including word-by-word fill with accelerated movement. It removes hidden animation work and fixes repeated restarts of the scroll animation when short pause rows collapse.

### Fixes and reliability

- **Hidden pauses stop animating.** Musical notes now animate only in the active pause near the visible area. Distant pause rows do not create decorative SVG elements. Previously, every pause could keep three invisible animations running for the entire song.
- **Bounded lyric painting.** Blurred text and pause decorations are painted near the viewport instead of across the full moving list. Distant lines retain their actual text layout and height, preserving wrapping, scrolling and seeking without estimated row sizes. The visible range follows automatic movement, manual scrolling and window resizing.
- **Accelerated movement no longer keeps restarting after a short pause.** The scroll target uses the final layout of collapsing pause rows, with precise coordinates that account for interface scaling. Subpixel rounding noise no longer repeatedly restarts the easing. Large jumps reposition directly instead of animating through a long offscreen section.
- **Cue changes avoid restyling the entire song.** Animation durations are applied to the moving track and the affected rows, rather than inherited from a changing property on the whole lyric stage.
- **Fewer measurements during pause animations.** Vertical changes still update positioning, but no longer rebuild word measurements on every frame of the pause's height animation. Word geometry is refreshed when the width, font or active line changes.

### Documentation and packaging

- Application and Windows installer version updated to 1.4.2, explicitly marked **Bug Fix** in the update window.
- Automated checks cover row visibility, distant pause decorations, bounded viewport lookup and the existing lyric timing behavior.
- A separate production-component Playwright test exercised word-by-word fill with accelerated movement, continuous fill, short pauses, distant seeking, manual scrolling, a narrow pane, 125% scaling and reduced motion. No Tauri dev player was launched.
- In a synthetic 1,200-row test with 4× CPU throttling, the worst measured steady-playback frame gap in word/accelerated mode fell from about 817 ms to about 50 ms; the new 95th percentile was about 33 ms. These are isolated browser measurements, not a guarantee for every device or for the full application's background workload.

### Known issues

- Rejected listening-history writes were previously observed in a dev build. Their cause and impact on packaged releases remain unconfirmed; this patch does not change that path.
- Seeking in DRM-protected SoundCloud tracks through browser playback may remain unavailable. Browser capture can still take close to the track's duration, depending on the track and account.

### Download

## Русский

### О релизе

Выпуск Bug Fix с исправлениями зависаний лирики, в том числе в режиме заполнения по словам с ускоренным движением. Убрана работа скрытых анимаций и исправлены повторные перезапуски движения списка при сворачивании коротких пауз.

### Исправления и стабильность

- **Скрытые паузы больше не анимируются.** Нотки анимируются только у текущей паузы рядом с видимой областью. У далёких строк пауз не создаются декоративные SVG-элементы. Раньше каждая пауза могла поддерживать три невидимые анимации на протяжении всей песни.
- **Ограничена область отрисовки лирики.** Размытый текст и декоративные нотки отрисовываются рядом с экраном, а не по всей длине движущегося списка. Далёкие строки сохраняют настоящую вёрстку и высоту текста: переносы, прокрутка и перемотка работают без приблизительных размеров строк. Видимая область следует за автоматическим движением, ручной прокруткой и изменением окна.
- **Ускоренное движение больше не перезапускается после короткой паузы.** Цель прокрутки рассчитывается по итоговому расположению сворачивающихся пауз с точными координатами, учитывающими масштаб интерфейса. Шум округления долей пикселя больше не перезапускает разгон анимации. При большом скачке список сразу перемещается к нужному месту вместо пролёта через длинную невидимую часть текста.
- **Смена строки не пересчитывает стили всей песни.** Длительность анимации задаётся движущемуся списку и затронутым строкам, а не наследуется от меняющегося свойства всей области лирики.
- **Меньше измерений во время анимации пауз.** Вертикальные изменения по-прежнему обновляют положение списка, но больше не перестраивают измерения слов на каждом кадре изменения высоты паузы. Геометрия слов обновляется при изменении ширины, шрифта или активной строки.

### Документация и сборка

- Версия приложения и установщика Windows обновлена до 1.4.2; в окне обновлений выпуск явно помечен как **Bug Fix**.
- Автоматические проверки охватывают видимость строк, декорации далёких пауз, ограниченный поиск видимой области и прежнюю логику таймингов лирики.
- Отдельный Playwright-тест production-компонента проверил заполнение по словам с ускоренным движением, сплошное заполнение, короткие паузы, дальнюю перемотку, ручную прокрутку, узкую область, масштаб 125% и уменьшение анимации. Tauri dev-плеер не запускался.
- В синтетическом тесте на 1 200 строк с четырёхкратным замедлением CPU худший измеренный интервал между кадрами установившегося воспроизведения в режиме по словам с ускорением сократился примерно с 817 до 50 мс; новый 95-й процентиль составил около 33 мс. Это замеры отдельного компонента в браузере, а не гарантия для любого устройства и фоновой нагрузки всего приложения.

### Известные проблемы

- Ранее в dev-сборке замечены отклонённые записи истории прослушиваний. Их причина и влияние на устанавливаемые релизы пока не подтверждены; этот патч не меняет соответствующий механизм.
- Перемотка DRM-защищённых треков SoundCloud через браузер по-прежнему может быть недоступна. Браузерный захват может занять почти всю длительность песни в зависимости от трека и аккаунта.
