# Tempo · библиотека: три варианта

Кликабельное превью: `http://localhost:1420/docs/design/library-redesign/index.html` при запущенном dev-сервере. Это отдельная демонстрация: она не меняет библиотеку и не воспроизводит аудио. Плейлисты, счётчики и сочетания источников в примерах демонстрационные.

Пять экранов в каждом варианте: плейлисты, альбомы, локальные страницы плейлиста, альбома и исполнителя. Смена варианта сохраняет выбранный экран.

## Общий язык

- Цвет: graphite #121016, elevated #201a24, pink #f14d78, soft pink #ffa0b9, text #f4f0f4, muted #a49aa8. Цвета привязаны к CSS-переменным; доступны графитовый, вишнёвый фон и фон с обоями.
- Шрифт: текущий стек Tempo Segoe UI Variable / Segoe UI; Bahnschrift для крупных названий. Без добавления внешних шрифтов.
- Мягкое стекло у боковой панели, плейбара и всплывающих окон. В контенте размытие локализовано в шапке и не применяется к каждой обложке при прокрутке.
- Иконки Lucide и существующие иконки источников Tempo. Настоящие публичные обложки и аватарки из музыки, уже доступной в локальном каталоге; пользовательские списки/история/состояние аккаунта не включены.

## A · Воздух

    [навигация]  [название / поиск / действия]
                 [обложка] [обложка] [обложка] ...
    Детали:      [обложка] [название и действия]
                 [единый широкий список треков]

Обложки на первом плане; много места между коллекциями, привычные широкие списки песен, спокойная полупрозрачная шапка.

## B · Фокус

    [навигация]  [поиск / сортировка]
                 [обложка | название | счётчик | действия]
    Детали:      [обложка + инфо] | [треки / альбомы]

Более плотный каталог; квадратные миниатюры и лёгкие строки. В деталях обложка с информацией закреплены слева, музыка занимает правую часть. Другие списки и тот же набор действий без повторения шапки на пол-экрана.

## C · Панорама

    [навигация]  [крупная коллекция] [обложки]
                 [широкая карточка] [широкая карточка]
    Детали:      [название / действия  |  большая обложка]
                 [широкий список треков]

Выразительные широкие шапки с приглушённым фоном из обложки; горизонтальные плейлисты, более крупный первый альбом и небольшой акцентный цвет. Контент остаётся контрастным, фон затемняется.

## Что работает в прототипе

Навигация между всеми экранами и тремя вариантами, поиск/сортировка/фильтры, избранное, создание и переименование демонстрационного плейлиста, меню коллекций и треков, выбор песни в демо-плеере, переключение/перемотка без аудио, раскрытие обложки, вкладки исполнителя. Escape и клик по фону закрывают окна; фон при этом не реагирует на клик. Данные демонстрации изолированы от приложения.

Превью сохраняет варианты для сравнения. Выбранное для рабочего плеера оформление указано ниже.

## Выбранное оформление

10 ноября 2026: вариант A принят только для списка плейлистов. Вариант C принят для списка альбомов и всех локальных страниц коллекций: плейлиста, альбома, исполнителя и подборки. Эти экраны перенесены в рабочее приложение с общими компонентами оформления; действия используют существующие данные и API. Превью выше сохраняется как история вариантов.
