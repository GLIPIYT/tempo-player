# Проверка музыкальных сервисов

Проверено 25 сентября 2026 года. Сохраняем фактические результаты и ограничения для продолжения работы над Tempo 1.0.

## TheAudioDB: портреты исполнителей

- Реальный запрос `search.php?s=coldplay` вернул Coldplay и портрет; URL изображения ответил `200 image/jpeg`.
- Бесплатный API v1 работает с ключом `123`; документация указывает максимум один результат для поиска исполнителя и 30 запросов в минуту для бесплатного уровня. В документации область лимита (IP, ключ или аккаунт) не уточнена, поэтому считать его IP-лимитом нельзя.
- В Tempo поиск запускается вручную; найденный портрет сначала показывается как предпросмотр и сохраняется в локальное хранилище только после подтверждения.
- Условия разрешают API для разработки, но запрещают публикацию приложений в app store без платной подписки. Перед выпуском Tempo в магазин нужно отдельно проверить применимость этого ограничения и лицензию выбранного изображения.

## SoundCloud: рекомендации и волна

- Текущий интегратор Tempo получает `client_id` со страницы SoundCloud и обращается к неофициальному `api-v2.soundcloud.com`.
- Живой запрос `/tracks/293/related?limit=5` вернул пять рекомендаций. В ресурсе трека был `station_urn`; `/system-playlists/{station_urn}` вернул 50 видимых треков для публичного тестового трека Flickermood.
- В официальной API-спецификации есть `GET /tracks/{track_urn}/related`, `GET /system-playlists/{urn}` и поле `station_urn`. Но запрос к официальному домену `api.soundcloud.com` без OAuth получил `401`; руководство требует OAuth 2.1. Доступ к публичным ресурсам через Client Credentials тоже требует `client_secret`, который нельзя безопасно встраивать в распространяемый desktop-клиент.
- Практичный кандидат для будущего режима **Wave** — начать станцию по текущему треку, получить станционные треки, а при отсутствии станции запросить related tracks. Добавлять в очередь только доступные для воспроизведения элементы, без дубликатов; продолжать подбор ближе к концу очереди. В первой версии использовать существующую интеграцию Tempo с приватным endpoint, учитывая, что SoundCloud может изменить её без предупреждения.
- Не путать музыкальную «волну» с waveform. В `waveform_url` приходит изображение waveform, а не список рекомендаций; официальная статья описывает PNG 1800×280 для отображения формы трека.

## YouTube Music: скорость поиска

Проверка на управляемом `yt-dlp 2026.08.19` и одинаковом запросе `radiohead`:

| Операция | Время |
| --- | ---: |
| Поиск 20 треков YouTube Music | 3,05 с |
| Раскрытие 4 альбомов последовательно | 13,15 с |
| Те же 4 альбома параллельно | 4,31 с |

Поиск треков не требует уменьшения лимита или задержки ввода: основное ожидание было в последовательном раскрытии карточек альбомов/исполнителей/плейлистов. Реализация запрашивает до четырёх страниц одновременно и отправляет карточку по готовности. Замер параллельного варианта включает запуск PowerShell-задач, поэтому не является точным временем работы потоков Tempo; он показывает выигрыш за счёт параллельных сетевых запросов.
