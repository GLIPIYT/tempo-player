# Настройки: выбранный вариант A

Основой нового экрана остаётся структура варианта A из
[`settings-variants.html`](./settings-variants.html). Правый общий пример убран:
предпросмотр находится рядом с настройками, на которые он реагирует.

## Поведение при переносе в Tempo

- **Тема:** миниатюры показывают готовые палитры. При выборе темы или изменении
  собственного акцентного цвета обновляются связанные примеры, включая цвет
  визуализатора при включённом параметре «Цвет темы».
- **Фон:** в области предпросмотра отображается *текущее установленное* фоновое
  изображение пользователя. После импорта или удаления фон меняется сразу.
  Затемнение и размытие применяются к этому же изображению по мере движения
  ползунков, без ожидания сохранения.
- **Текст:** небольшой пример заголовка и подписи показывает размер и масштаб.
- **Плеер:** локальный пример отражает волновой прогресс и выбранную компоновку.
- **Визуализатор:** отдельная анимированная область показывает выбранный вид
  (столбцы, волна, линия или выключен), детальность, высоту, прозрачность,
  сглаживание и зеркальность. Цвет берётся из активной темы при включённом
  параметре «Цвет темы»; при выключенном — из нейтрального цвета. При смене темы
  пример перекрашивается сразу. В режиме уменьшенной анимации он остаётся
  неподвижным, но продолжает отражать изменения параметров.

HTML-файл — самостоятельный макет. Его демонстрационная картинка не связана с
настройками установленного Tempo; при реализации нужно читать активный путь
фонового изображения из настроек приложения.
