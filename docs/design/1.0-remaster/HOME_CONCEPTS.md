# Главная Tempo — четыре отдельных макета

Статус: **вариант A выбран и перенесён в главную страницу приложения**. `home-variants.html` остаётся демонстрационным превью четырёх вариантов. Макеты A–D используют одну палитру, одни обложки и один набор демонстрационной музыки; в приложении вариант A берёт настоящие подборки и обложки из медиатеки.

## Общая основа

- Фиксированные области: заголовок окна, навигация слева, верхняя строка поиска и плеер снизу. Их геометрия и цвет одинаковы во всех вариантах.
- Цвета: фон `#0f1416`, навигация `#141a1b`, поверхность `#1b2324`, линия `#2d3938`, текст `#eef2ef`, вторичный текст `#a1aea8`, спокойный акцент `#bedac5`, тёплый акцент из обложек `#dca36e`.
- Заголовки — Bahnschrift с системным запасным шрифтом, текст — Segoe UI Variable. Радиусы: 10–18 px по роли элемента; обложка остаётся квадратной.
- Везде один и тот же пример: микс «Ночной маршрут», треки «Nightline», «Glass Tides», «Red Corridor», «Static Bloom», подборки «В этот час», «Слушали недавно», «Часто слушаете» и «Недавно добавлено». Это примеры для сравнения компоновки, а не реальные данные пользователя.
- Локальные обложки в `home-assets/`: `night-transit.png` — дождливая платформа и поезд, `sea-glass.png` — стеклянные формы, `red-corridor.png` — оранжевая лента в коридоре. Они сгенерированы для этого превью через встроенный imagegen без текста и логотипов. Четвёртая обложка в HTML выполнена CSS.

## A — Сцена

Большая музыкальная витрина. Первым показывается микс текущего часа: описание и действие слева, крупная обложка справа. Через три секунды витрина плавно сменяется следующей подборкой; переход длится 600 мс. В демонстрации три подборки, а в приложении их количество должно определяться реальными данными. Ниже — горизонтальная полоса «Слушали недавно», затем компактные полки «Часто слушаете» и «Недавно добавлено».

В нижней кромке витрины кнопка «Все подборки» с миниатюрами и счётчиком. Она раскрывает компактный список с обложкой, типом, названием и числом треков; выбор сразу показывает нужную подборку. Рядом есть стрелки и точки для ручного переключения. Автоматическая смена приостанавливается при наведении, работе с клавиатурой, открытом списке и неактивной вкладке. После ручного выбора даётся больше времени на чтение. При системной настройке уменьшения анимаций смена по таймеру отключена.

```text
┌──────────────────────────────────────────────────────────────────┐
│ приветствие и поиск                                              │
├──────────────────────────────────────────────────────────────────┤
│ сменяемая подборка, название и действия      │ крупная обложка   │
│ [миниатюры Все подборки 03 ▾]              ◀  ● ● ●  ▶       │
│ раскрываемый список подборок по нажатию кнопки                 │
├──────────────────────────────────────────────────────────────────┤
│ слушали недавно: три широких элемента                            │
├────────────────────────────────────┬─────────────────────────────┤
│ часто слушаете: обложки            │ недавно добавлено           │
└────────────────────────────────────┴─────────────────────────────┘
```

## B — Пульт

Первый экран отвечает на вопрос «что включить сейчас». Вместо высокого баннера вверху идут три широкие карточки последних прослушиваний. Ниже две колонки: слева микс текущего часа и рейтинг часто слушаемого, справа новые треки и быстрый вход в медиатеку. Плотнее A, но все действия и названия остаются крупными.

```text
┌──────────────────────────────────────────────────────────────────┐
│ приветствие, число треков, действия                              │
├──────────────────────────────────────────────────────────────────┤
│ слушали недавно:     1     │     2     │     3                   │
├───────────────────────────────────────┬──────────────────────────┤
│ микс этого часа                       │ недавно добавлено       │
├───────────────────────────────────────┤ быстрый вход в библиотеку│
│ часто слушаете: ранжированный список  │                          │
└───────────────────────────────────────┴──────────────────────────┘
```

## C — Полка

Главная строится вокруг обложек. Слева крупная обложка часто слушаемого трека, справа мозаика других знакомых треков с читаемыми подписями поверх нижнего градиента. Ниже — две спокойные секции: микс этого часа и новые поступления в библиотеку. Это самый визуальный вариант; рейтинг становится навигацией по музыке.

```text
┌──────────────────────────────────────────────────────────────────┐
│ короткое приветствие и переход в медиатеку                       │
├────────────────────────────────┬─────────────────┬────────────────┤
│ крупная обложка / №1           │ обложка / №2    │ обложка / №3   │
│                                ├─────────────────┼────────────────┤
│                                │ обложка / №4    │ обложка / №5   │
├────────────────────────────────┴─────────────────┴────────────────┤
│ микс этого часа                    │ недавно добавлено            │
└────────────────────────────────────┴───────────────────────────────┘
```

## D — Ритм

Главная как короткая история прослушивания. Вертикальная линия связывает три последовательных состояния: музыка, к которой возвращались недавно; текущий часовой микс; новые треки в медиатеке. Справа отдельная узкая колонка с часто слушаемыми треками. Этот вариант лучше подчёркивает личные данные и время, чем каталог обложек.

```text
┌──────────────────────────────────────────────────────────────────┐
│ приветствие и текущее время                                      │
├───────────────────────────────────────────┬──────────────────────┤
│ недавно  ●  треки, которые слушали         │ часто слушаете       │
│          │                                │ 1 / 2 / 3 / 4        │
│ сейчас   ●  микс этого часа, крупнее       │                      │
│          │                                │                      │
│ новое    ●  добавленные треки              │                      │
└───────────────────────────────────────────┴──────────────────────┘
```

## Реализация в приложении

В `HomePage.tsx` оставлены миксы текущего часа, часто слушаемые треки, недавно добавленные и прослушанные, добавление папки, пересканирование, скрытие разделов до завтра, контекстное меню и перетаскивание треков. Витрина A использует актуальные подборки из `hourMixes`; раскрываемый список показывает все доступные подборки и их настоящее число треков. Кнопка «Посмотреть треки» раскрывает треки выбранного микса. Короткие полки ниже витрины можно развернуть, чтобы увидеть все элементы, доступные на прежней главной. Превью не вводит сохранение позиции трека или прогноз музыки на будущие часы. Для пустой медиатеки остаётся экран с добавлением папки.

3. `red-corridor.png`: red-orange silk ribbon through a deep violet architectural corridor, dramatic side light, soft haze, editorial music artwork; square, no text/logo/UI.
