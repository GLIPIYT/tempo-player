# Tempo: превью визуальной полировки

01.10.2026 · [Открыть макеты](polish-preview.html) · [Технические предложения](polish-research.md)

## Область работы

Это самостоятельные интерактивные макеты. Код и поведение самого плеера не изменены. Данные треков, статистика, номер предлагаемого обновления и прогресс в окнах — примеры, а не сведения о текущей сборке или доступном релизе. Ручную проверку выполняет пользователь.

Верхняя панель переключает экран, компоновку A/B, ширину окна и цвета. A/B сравнивают размещение элементов, а не цветовые темы. Два произвольных цвета меняют палитру, векторные знаки и визуализатор без перезагрузки макета.

## Общий интерфейс

- Единственное название Tempo с иконкой — в заголовке окна; навигация начинается сразу с «Главная».
- Заголовки, названия треков и лирика остаются белыми; градиент обозначает действия и активные состояния.
- Переключатели 49 × 28 px, единые ползунки с крупным бегунком, читаемая подпись и значение рядом. Клиентский Discord Application ID отсутствует.
- Dropdown и разворачиваемые секции используют общий размер текста и отступы. Длинные списки ограничены по высоте.
- Настройки центрированы с полями по сторонам; на узком окне группы перестраиваются в колонку, сайдбар сужается до иконок.
- Тёмный скроллбар, заметный keyboard focus, режим reduced motion. Контролы не требуют наведения для доступа.

## Что можно попробовать

- Переключить A/B на каждом экране, уменьшить окно, выбрать любую из трёх палитр или свои два цвета.
- В «Общее» нажать переключатель, открыть dropdown, изменить ползунок; в B выбрать другую группу.
- Во «Внешнем виде» менять прозрачность/размытие текущего изображения, стиль и параметры анимированного визуализатора; в B сворачивать секции.
- Выбрать Pulse/Orbit: меняются знак в заголовке и образцы для трея/панели задач.
- В «Контраст» включать/выключать контур, менять яркость демонстрационного фона.
- В каталогах, профиле и формах использовать предусмотренные в макетах кнопки; редактор показывает создание артиста/альбома без отдельного большого окна.

Кнопки воспроизведения, файлов, установки и сохранения имитируют действие внутри макета; они не меняют библиотеку. Для будущей реализации этих действий нужен отдельный этап. Цветовой outline здесь демонстрируется на образце, автоматическое измерение реального фонового изображения ещё не реализовано.

## Иконки

Исходные выбранные растровые концепты сохранены в `docs/brand/icon-concepts/`. В макете сделана **векторная адаптация**, а не точное увеличение AI-изображения: Pulse сохраняет симметричный ритм столбиков и длинную центральную полосу, Orbit — ноту с разомкнутой орбитой. Знаки крупнее внутри поля; весь контур сохраняется в маленьком размере.

Шесть SVG в `docs/brand/icon-concepts/vector/` имеют размер 2048 × 2048 и масштабируются без потери резкости. Повторная генерация: `node docs/design/1.0-remaster/polish-export-icons.mjs`. В макете SVG получают актуальные цвета темы.

До внедрения нужно согласовать точность формы и толщину штрихов на 16/24/32 px. Иконку внутри интерфейса и в трее можно перекрашивать при смене темы. Tauri предоставляет [setIcon для окна](https://v2.tauri.app/reference/javascript/api/namespacewindow/#seticon), но поведение панели задач зависит также от кеширования оболочкой Windows; закреплённый ярлык и файл EXE имеют встроенную статическую иконку. Превью не обещает, что системные иконки уже динамически перекрашиваются.

## После выбора

Сначала общий стиль настроек, окон, мини-плеер и выбранные страницы; затем отдельные функциональные изменения из исследовательской заметки. Все текущие функции нужно сохранить при переносе дизайна. Для adaptive contrast предлагается анализировать фон только при смене изображения/обработки, применять контур лишь к тексту поверх обоев, не ко всему UI и не к иконкам.
