# Tempo 1.6.0 visual changelog

The [poster composition](poster.html) uses the eight WebP figures in `figures/`. The full-size [release poster](tempo-1.6.0-changelog.webp) is 1280 pixels wide. The update dialog ships a separate 720-pixel version and links to the original.

The figures are isolated renders of production Tempo screens. The UI uses the display data and artwork already published with 1.5.0. Settings values, the example playlist report, network replies and waveform peaks are staged for the illustration. No audio is played and the fixture does not access a real library or sign-in session.

To render a screen, start Vite and open `frames.html?frame=home|light|playlist|stats|playback|track|lyrics-view|network`. For the statistics, track settings and network figures, capture the respective dialog or menu element. Open `poster.html` at a viewport width of 1280 pixels to export the composition.
