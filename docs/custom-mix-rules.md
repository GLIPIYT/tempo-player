# Пользовательские подборки

На главной откройте **Все подборки → Своё правило**. Сохранённая подборка появляется в этом же списке. На странице подборки доступны изменение правила, обновление списка и удаление через редактор. Сохранение правила не создаёт обычный плейлист и не скачивает все его результаты.

Стрелка рядом с **Названием подборки** переключает поле на **Описание подборки**. Название сохраняется отдельно. В описании доступно до 150 символов; счётчик становится красным, когда остаётся 50 символов или меньше.

**Количество песен** задаётся от 1 до 50. **Интервал пересборки** — от 0 до 24 часов с шагом 10 минут. При нуле список собирается заново при открытии подборки. Положительный интервал сохраняет состав между открытиями и перезапусками до истечения срока. Пока открыта главная или сама подборка, срок проверяется таймером. После закрытия Tempo новая генерация выполняется при следующем открытии. Кнопка **Обновить** пересобирает список сразу; ошибка пополнения не заменяет доступный прежний состав пустым.

## Фильтры

| Настройка | Как работает |
| --- | --- |
| Исполнители | Вайтлист оставляет выбранных исполнителей; блэклист исключает их. Пустой список ничего не ограничивает. |
| Время прослушивания | Время суток из истории, с шагом 30 минут. Это не дата выпуска песни. |
| Средняя доля прослушанного | Средняя доля покрытия трека в сохранённой истории, ограниченная 0–100%. Для нестандартного диапазона нужна история прослушивания. |
| Жанры: вайтлист | Выбранные жанры образуют группу, долю которой задаёт следующий диапазон. Остальные места могут занимать другие жанры. |
| Жанры: блэклист | Выбранные жанры полностью исключены; диапазон их доли выключен. |
| Источники | Локальные файлы, SoundCloud и YouTube Music. |
| Забытые песни | Диапазон дней с последнего прослушивания и диапазон доли таких песен. У ещё не прослушанного трека нет даты последнего прослушивания. |

По умолчанию выбираются 24 песни. Если жёстким условиям соответствует меньше выбранного количества, список будет короче. Доли жанров и забытых песен подбираются совместно: при нехватке подходящих сочетаний показано предупреждение. Пустая история не выдаётся за полное прослушивание.

## Особые правила и пресеты

**Для этого часа** использует текущий час и историю, полностью заменяя ручной диапазон времени. **На повторе**, **Новое для вас**, **Без пропусков** добавляют критерии соответствующих встроенных подборок. В меню **⋯ → Скопировать правило** можно перенести критерии существующей подборки, а затем изменить их. Копируются правила, а не зафиксированный набор песен.

**Дополнять жанры с SoundCloud** разрешает отдельные ограниченные запросы при нехватке подходящих библиотечных песен. Используются выбранные жанры, знакомые исполнители и связанные треки, а также доступный профиль вкуса. Название жанра само по себе не подтверждает сходство песни. Сетевые результаты временные; явное добавление в лайки или плейлист сохраняет трек обычным способом. Ошибка сети не удаляет локальную часть подборки.

Список жанров содержит распространённые варианты SoundCloud и жанры библиотеки. Это не закрытая классификация: SoundCloud разрешает собственные жанровые подписи. Источники: [жанры и теги SoundCloud](https://help.soundcloud.com/hc/en-us/articles/115003446007-Adding-a-genre-and-tags-when-uploading-a-playlist), [раздел Discover](https://soundcloud.com/discover).

## Сохранённая лирика и перемещённые файлы

В оформлении можно выключить заглавную букву в начале строк. Этот параметр меняет отображение; исходный текст и тайминги остаются прежними.

В **Настройки → Общее → Доп. обработка** находятся две функции. **Уточнять тайминги по вокалу** использует включённую в Tempo модель вокала для уточнения окончаний строк. Экспериментальный переключатель **Уточнять тайминги слов** сопоставляет уже известный текст строки с аудио через локальную Whisper tiny, загружаемую при включении. Обе функции обрабатывают аудио на компьютере и могут расходовать процессорное время и оперативную память; готовность показана отдельно под каждой функцией.

Уточнение слов работает в режиме заполнения по словам, с доступным локальным или кэшированным аудио. Обрабатываются строки из 2–48 слов в окне до 12 секунд; готовые тайминги источника и ручная разметка имеют приоритет. При недостаточной уверенности остаётся прежняя оценка таймингов. Параметр выключен по умолчанию. [Результаты реального запуска и ограничения проверки](research/known-text-worker-proof-2026-11-09.md).

При включённом кэшировании лирики доступен переключатель **Поиск по кэшированной лирике**. В общем поиске отдельная группа после библиотеки показывает до пяти совпадений по словам. Используется сохранённый текст, приоритет имеет закреплённая лирика. Провайдеры для этой группы не опрашиваются.

Фоновый индекс сохраняет SHA-256 аудиофайлов. Если файл пропал с известного пути, Tempo ищет совпадение имени и размера, затем проверяет содержимое по хэшу. Переименованный файл также можно найти по содержимому. При восстановлении сохраняются ID трека, плейлисты, история и лирика. Само отсутствие файла не удаляет запись.

Хэш должен быть сохранён **до перемещения**. Если Tempo ещё не успел его вычислить или содержимое файла изменилось, одного совпадения имени недостаточно для автоматической подстановки. Поиск идёт в фоне по доступным локальным каталогам и дискам; недоступный диск или папка не дают гарантии немедленного восстановления.
