# 🎵 Tempo

[English](README.md) · **Русский**

**Локальный десктопный музыкальный плеер.** Ваши файлы, ваша библиотека — без аккаунтов и облака, всё работает офлайн.

Собран на **Tauri 2 + React 18 + TypeScript** во фронтенде и **Rust + SQLite** под капотом. Ни Electron, ни бэкенд-сервера, ни телеметрии.

## ✨ Возможности

### Библиотека

- **Локальная библиотека** — укажите Tempo папки с музыкой (MP3, FLAC, M4A, AAC, OGG, Opus, WAV), и он соберёт из них коллекцию: альбомы, исполнители, треки.
- **Быстрое инкрементальное сканирование** — теги читаются через `lofty`, обложки альбомов извлекаются в каталог данных приложения. Неизменённые файлы (тот же размер + mtime) пропускаются, поэтому повторное сканирование почти мгновенное. Сканирование выполняется в потоках Rust и никогда не блокирует интерфейс.
- **Убрать, не удаляя** — трек можно скрыть из библиотеки: он останется скрытым и после пересканирования, а сам файл на диске не тронут.
- **Показать в проводнике** — переход от трека к его папке одним действием.
- **Контекстные меню везде** — по правому клику на треках, карточках альбомов и исполнителей и разделах главной доступны те же действия, что и в меню строки. Разделы можно скрыть до завтра.

### Воспроизведение

- **Полноценный движок воспроизведения** — очередь с шаффлом, повтором (выкл / все / один трек), перемоткой и громкостью; счётчики прослушиваний и история записываются автоматически.
- **Плеер не прерывается** — аудиоэлемент живёт вне дерева React, поэтому переходы по приложению никогда не обрывают трек.
- **Прогресс на панели задач** — позиция воспроизведения отражается на иконке в таскбаре Windows.
- **Волновой прогресс-бар** — опциональная замена обычной полосе.
- **Кроссфейд** — конец трека накладывается на начало следующего, от 1 до 12 секунд. По умолчанию выключен.
- **Визуализатор спектра** — живой спектр на полосе над плейбаром: столбики, волна или линия акцентным цветом темы, с настройкой детализации, высоты, непрозрачности и сглаживания. Читает тот же анализатор, что и сторож тишины, поэтому отражает то, что слышно на самом деле: после нормализации громкости и после рампы кроссфейда. Потоковые треки без кеша воспроизводятся мимо аудиографа, поэтому на них полоса остаётся пустой.

### Плейлисты и избранное

- **Плейлисты** — создание, переупорядочивание, переименование; треки добавляются из любого места приложения.
- **Лайки** — встроенный, всегда закреплённый плейлист «Likes».
- **Избранные исполнители и альбомы** — закрепляются в боковой панели рядом с плейлистами, в одном общем порядке с перетаскиванием.
- **Импорт и экспорт M3U8** — плейлисты можно переносить в Tempo и обратно.

### Тексты песен

- **Синхронизированная лирика** — из встроенных тегов, `.lrc`-файлов рядом с треком или, как фолбэк, из пяти онлайн-источников (lrclib, textyl, Musixmatch, lyrics.ovh, Genius).
- **Полноэкранный оверлей** — активная строка подсвечена, следующие видны заранее.
- **Закрепить и подстроить** — для конкретного трека можно закрепить нужный провайдер или даже лирику другой песни и сдвинуть тайминг с точностью до миллисекунд.

### За пределами локальной библиотеки

- **Провайдер SoundCloud** — поиск и стриминг с SoundCloud рядом с локальной библиотекой через единую абстракцию провайдеров. Потоки кешируются на диск с настраиваемым лимитом и вытеснением давно не игравшихся файлов; закешированный трек попадает в библиотеку автоматически.
- **Кэшировать перед воспроизведением** — опция: трек с SoundCloud скачивается целиком до начала. Первый запуск придётся подождать, зато дальше трек играет с диска, а не потоком мимо аудиографа — именно поэтому на нём работает визуализатор спектра.
- **Discord Rich Presence** — показывает, что вы слушаете: обложка, настоящий прогресс-бар и текущая строка лирики. Общение с Discord идёт через локальный IPC-пайп; по умолчанию выключено.

### Внешний вид

- **Плавающий мини-плеер** — компактное окно поверх всех окон, прижатое «пилюлей» к верхней кромке экрана. По клику разворачивается в обложку, транспорт, перемотку, громкость, избранное, повтор и шаффл; умеет сам раскрываться при смене трека и сворачиваться обратно. По умолчанию выключен.
- **Десять встроенных тем** — плюс пользовательский режим: задаёте базовые цвета и переопределяете отдельные токены.
- **Два вида плейбара** — классический оставляет полосу прогресса между кнопками управления и громкостью; современный переносит кнопки в центр, а полосу прогресса — на верхнюю кромку плейбара.
- **Свой шрифт и фон** — можно импортировать файл шрифта, поставить фоновое изображение с регулируемым затемнением и размытием, масштабировать интерфейс целиком.
- **Двуязычный интерфейс** — английский и русский из коробки или по языку системы.

### Обновления

- **Встроенный апдейтер** — Tempo проверяет новые релизы на GitHub при запуске и предлагает самый свежий из тех, что вы не пропустили. Описание обновления берётся из самого релиза, а скачивание и установка — одно действие: приложение закрывается и возвращается уже на новой версии. В настройках перечислены все релизы выше текущего, так что можно осознанно выбрать и более старый, а пропущенная версия снова появится, как только выйдет новее.

## 🧱 Технологии

| Слой | Технологии |
|---|---|
| Оболочка | Tauri 2 (без Electron) |
| Интерфейс | React 18 + TypeScript (strict) + Vite 6, иконки `lucide-react`, собственный CSS (без фреймворков) |
| Воспроизведение | Синглтон HTML5 `<audio>` + чистый контроллер очереди (шаффл-перестановка, режимы повтора), `hls.js` для SoundCloud |
| Бэкенд | Rust: `rusqlite` (bundled SQLite, режим WAL), `walkdir`, `lofty`, `reqwest`, `image` |
| Данные | Один файл SQLite в каталоге данных приложения; упорядоченные миграции через `user_version` |
| Поиск | SQL `LIKE`-запросы по трекам / альбомам / исполнителям, постраничные списки (500 на страницу) |

## 🚀 Начало работы

**Требования:** [Node.js 18+](https://nodejs.org), [Rust](https://rustup.rs) и [предварительные требования Tauri 2](https://tauri.app/start/prerequisites/) для вашей платформы.

```bash
# установить зависимости
npm install

# запуск в режиме разработки
npm run tauri dev

# сборка релизного установщика (Windows: NSIS .exe)
npm run tauri build
```

Фронтенд можно разрабатывать и отдельно (`npm run dev`) — Vite с горячей перезагрузкой на порту 1420. Но всё, что касается библиотеки и воспроизведения, требует ядра на Rust, поэтому для реальной работы нужен `tauri dev`.

Проверки:

```bash
npm run typecheck                                  # TypeScript, strict
cargo test --manifest-path src-tauri/Cargo.toml    # 62 юнит-теста на Rust
```

## 📁 Структура проекта

```
src/                  # React-фронтенд
  api/                #   типизированные обёртки над командами Tauri + подписки на события
  components/         #   общие UI-элементы, layout (боковая панель, панель плеера, очередь), онбординг
  dnd/                #   drag-and-drop для треков и избранного в боковой панели
  features/lyrics/    #   провайдеры лирики, разбор LRC, оверлей
  hooks/              #   асинхронные данные, лайки, папки, прогресс сканирования
  i18n/               #   переводы EN / RU
  pages/              #   Главная, Библиотека, Альбомы, Исполнители, Плейлисты, Поиск, Профиль, Настройки + детальные страницы
  player/             #   движок воспроизведения: контроллер, очередь, React-биндинги
  providers/          #   абстракция источников музыки (локальные файлы, SoundCloud)
  state/              #   навигация + сохраняемые настройки
  theme/              #   движок токенов + предустановленные темы
src-tauri/            # бэкенд на Rust
  src/database.rs     #   слой SQLite + миграции
  src/commands.rs     #   команды Tauri (Result<T, String>)
  src/scanner.rs      #   обход файловой системы + инкрементальное сканирование
  src/metadata.rs     #   извлечение тегов и обложек (lofty)
  src/lyrics.rs       #   онлайн-провайдеры лирики
  src/soundcloud*.rs  #   клиент SoundCloud API + кеш потоков
  src/discord.rs      #   Rich Presence через локальный IPC-пайп
```

Полная архитектура, модель данных и контракты модулей описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## 🗺️ Статус

`v0.6.0` — альфа, в первую очередь под Windows. Воспроизведение, сканирование библиотеки, плейлисты, избранное, лирика, поиск, SoundCloud, Discord-презенс, плавающий мини-плеер, контекстные меню по правому клику, два вида плейбара, кроссфейд, визуализатор спектра и встроенный апдейтер — всё работает. Релизный пайплайн пока собирает только установщик NSIS для Windows; при этом сам код не завязан на Windows нигде, кроме пути к IPC-пайпу Discord и прогресса на панели задач.

Что ещё предстоит: у фронтенда пока нет автотестов, а в CI нет линтера.
