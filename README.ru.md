## Tempo 1.5 — твоя музыка, твои правила

Очень крупное обновление: свои подборки, новый профиль, подробная история и больше возможностей для лирики.

- **Соберите свой микс.** Выберите исполнителей, жанры, источники, время и привычки прослушивания. Задайте от 1 до 50 песен и частоту пересборки. Копируйте готовые правила, перемещайте подборки и возвращайтесь к забытым песням.
- **Узнайте свой музыкальный день.** Открывайте месяц, день и час на графике. Сравнивайте время, запуски и дослушивания с предыдущим активным периодом, смотрите любимые треки и исполнителей.
- **Следите за каждым словом.** Синхронизированная лирика, подсветка слов, отдельный визуализатор и режим на весь экран. Дополнительное уточнение таймингов работает с локальным или полностью кэшированным аудио; анализ слов экспериментальный.
- **Пользуйтесь обновлённой медиатекой.** Новый вид плейлистов, альбомов, исполнителей и профиля. Выбирайте обложку нового плейлиста, переименовывайте его прямо в шапке и открывайте привычные действия через контекстные меню.

## Всё для музыки — в Tempo

- **Локальная медиатека.** Добавляйте папки с MP3, FLAC, M4A, AAC, OGG, Opus и WAV. Tempo читает теги и обложки, а музыку можно искать и сортировать по трекам, альбомам, исполнителям и плейлистам. Исходные файлы остаются на своих местах.
- **Поиск музыки в сети.** Ищите музыку на SoundCloud и YouTube Music рядом со своими треками. Добавляйте найденное в очередь, а поддерживаемые треки сохраняйте в кэш для дальнейшего воспроизведения.
- **Управление воспроизведением.** Используйте плейлисты, перемешивание, повтор, скорость, кроссфейд и выравнивание громкости. Десятиполосный эквалайзер работает с локальными и кэшированными треками; для визуализации доступны волна и спектр.
- **Лирика и история.** Следите за текстом по строкам и словам, редактируйте и сшивайте лирику. Новый профиль показывает прослушивания с подробностями по месяцам, дням и часам.
- **Оформление под себя.** Выбирайте тему, фон, шрифт и масштаб интерфейса. В Tempo также есть плавающий мини-плеер, Discord Rich Presence и импорт с экспортом плейлистов M3U8.
- **Рекомендации на главной.** Слушайте ленту рекомендаций SoundCloud и отдельную подборку часто прослушиваемого жанра.

## Горячие клавиши

Они работают, когда окно Tempo активно, а фокус не находится в поле ввода или элементе управления.

| Клавиша | Действие |
|---|---|
| `Пробел` | Воспроизведение или пауза |
| `←` / `→` | Предыдущий или следующий трек |
| `Ctrl` + `←` / `→` | Перемотка на одну секунду назад или вперёд |
| `↑` / `↓` | Изменить громкость на 5% |
| `M` | Выключить или восстановить звук |
| `S` | Включить или выключить перемешивание |
| `R` | Переключить повтор: выключен, всё, один трек |

## Установка

Скачайте актуальный установщик Windows на странице [GitHub Releases](https://github.com/GLIPIYT/tempo-player/releases). Для релизов используется установщик NSIS.

## Сборка из исходного кода

Для сборки нужны Node.js 22, стабильная версия Rust и [зависимости Tauri для Windows](https://tauri.app/start/prerequisites/).

```bash
git clone https://github.com/GLIPIYT/tempo-player.git
cd tempo-player
npm ci
npm run tauri dev
```

Собрать установщик Windows можно командой:

```bash
npm run tauri build
```

`npm run dev` запускает только фронтенд. Для медиатеки, воспроизведения и системных интеграций требуется приложение Tauri.

## Проверки

Запустите те же проверки фронтенда и Rust, что входят в CI:

```bash
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
```

GitHub Actions проверяет типы, запускает Vitest, проверяет порядок хуков и ESLint, линтит workflow-файлы и запускает Rust-тесты при push и pull request в `main`.

## Технологии

| Область | Стек |
|---|---|
| Десктоп-приложение | Tauri 2 |
| Фронтенд | React 18, TypeScript и Vite |
| Нативные сервисы | Команды Rust для сканирования, метаданных, сети и интеграции с системой |
| Хранение | SQLite; музыкальные файлы остаются в исходных папках |
| Аудио | Воспроизведение через HTML audio и `hls.js` для потоков SoundCloud |

Фронтенд обращается к Rust через типизированные обёртки в `src/api/`. Структура приложения и потоки данных описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Локальные данные и онлайн-сервисы

Для локальной медиатеки аккаунт не нужен. Данные библиотеки, плейлисты и история прослушиваний хранятся на устройстве. Для сетевого поиска, потоков, лирики, рекомендаций и проверки обновлений требуется интернет; доступность зависит от соответствующего сервиса.
